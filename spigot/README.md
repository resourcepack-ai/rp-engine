# SpigotMC resource page

What goes into the fields of RP Engine's page on spigotmc.org. Titles and tag
lines on the most-downloaded resources never pass 100 characters, so treat that
as the limit for both.

**Title** (93)

```
RP Engine | Items, Blocks, Furniture, Models, Emotes, Vehicles, GUIs, HUDs, Dialogs | 1.19.4+
```

**Tag line** (95)

```
Custom items, blocks, furniture, animated models, emotes and vehicles from YAML. Free, no mods.
```

**Description**: paste `description.bbcode` as it is. The `*_URL` placeholders
in its `[IMG]` tags are images still to be made: a banner, a features GIF and an
editor GIF. Keep text out of the images; SpigotMC's guidelines ask for the words
to be in the description.

**Links**: source code `https://github.com/resourcepack-ai/rp-engine`, support
`https://resourcepack.ai/discord`, documentation
`https://resourcepack.ai/docs/rp-engine`.

The "What it connects to" section is a promise: it has to stay true of
`Heartbeat`, `/rp edit`, `/rp sync` and `/rp distribute`. Change what any of
them sends and this page changes with it.
